About the artwork

The Reliquary of Memory investigates remembrance as a process of selection, repetition, and reconstruction. Holographic hands navigate a sequence of ordinary moments centered on a shared public space, treating memory as both personal experience and digital archive. The work considers how technological interfaces influence which moments are preserved, revisited, and reinterpreted and how each act of individual recall can alter the meaning of the past.

If remembering changes the past, was the memory ever truly ours?
